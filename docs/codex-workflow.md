# Codex CLIを使ったReachy Miniの実機操作の進め方

この文書は、2026年11月2日に2体を順番に起動・停止した際の協働方法を、再現時の参考として整理したものです。実際に送るPowerShellコマンドと事前条件は[2体の操作順序](../pair-start-stop.md)および各機の手順にあります。

## 人間・ChatGPT・Codexの役割

| 担当 | 今回の役割 |
|---|---|
| 人間（実験者） | 目的と優先順位を決め、各操作を承認し、実機の姿勢・異音・引っかかりを観察して最終判定する |
| ChatGPT | 方針と選択肢を相談し、資料や手順をレビューする |
| Codex CLI | 公式API/SDKと環境を調べ、コマンドを提示し、承認された操作を実行してAPI応答・状態を確認する |

CodexがHTTP APIから状態を読めても、機体の物理的な動作は人間が確認します。

## Codex CLIを使う前の準備

Codex CLIの導入とサインインは[OpenAIの公式案内](https://learn.chatgpt.com/docs/codex/cli)を参照してください。Windows PowerShellで操作手順のMarkdownがある作業ディレクトリへ移動し、Codex CLIを起動します。別の場所から作業ディレクトリを指定する場合は、公式の[`-C`オプション](https://learn.chatgpt.com/docs/cli/reference)を使えます。

```powershell
codex
```

作業前に、Codexが[Lite](../lite-operations.md)、[Wireless](../wireless-operations.md)、[2体の操作順序](../pair-start-stop.md)を参照できることを確かめます。HTTP APIを使うには、各管理サーバーが応答する環境も必要です。配置と確認方法は[実行環境](environment.md)に記載しています。

## 自然言語での依頼例

> 現在のdaemon、モーター、実行中動作、アプリ、ロックを確認し、可能なら機体を起動したいです。状態を変える前にコマンドと影響を提示し、私の承認を得てください。実機の動作結果は私が知らせます。

これは**公開資料向けの例文**であり、2026年11月2日に入力した依頼の逐語記録ではありません。

## 協働の操作フロー

```mermaid
flowchart LR
    read["手順を参照"] --> get["GETで状態確認"] --> choose["次の操作を選択"] --> approve["人間が承認"] --> post["PowerShellからAPI実行"] --> api["Codexが応答・状態確認"] --> observe["人間が実機を観察"]
```

状態確認では、daemon/backend、モーター、実行中動作、アプリ、ロックなどを読み、各手順の続行条件に照らします。必要な処理と機体への影響を人間に示してから、状態変更のコマンドを個別に実行します。CodexはAPI応答と後続の状態を確認し、人間は通常姿勢または収納姿勢、異音や引っかかりの有無を確認します。APIの受付IDや実行中動作0件だけで物理的な成功とは判断しません。

## 承認と安全の境界

GETによる状態照会とPOSTによる状態変更を区別し、今回の手順では状態照会を含む各操作のコマンドと影響を人間が確認して承認しました。チーム内の運用方針と、Codexのファイルアクセス制限・操作承認は別の仕組みです。再現時も自分の環境の制限と承認条件を確認してください。

タイムアウトしてもPOSTが受理済みの場合があります。すぐに再送せず、GETで状態を確認します。モーター通信エラー、異音、引っかかり、過負荷、想定外の動きがあれば追加の動作を指示せず、状態を確認します。周囲から手や物を離してから動作させます。

今回の最終操作ではWirelessへのSSHは使わず、HTTP APIを利用しました。2体の起動・停止にOpenAI APIキーは不要でした。

## モデルとセッションの分担

当時の作業記録では、Lite側にGPT-6 Luna、Wireless側にGPT-6 Solを使いました。接続方式、作業の難易度、利用枠、トークン消費を考慮した分担であり、これらのモデルは再現の必須条件ではありません。複数セッションから2体を同時に操作する安全性は実証していません。

## 再現時の範囲

実機で確認した範囲はWireless→Liteの順次起動と、Lite→Wirelessの順次収納・停止です。2体の自律協調・同期制御、音声と撮影を組み合わせた実機の一往復は検証していません。機体への具体的なコマンドは[2体の操作順序](../pair-start-stop.md)、[Liteの操作手順](../lite-operations.md)、[Wirelessの操作手順](../wireless-operations.md)を参照してください。
